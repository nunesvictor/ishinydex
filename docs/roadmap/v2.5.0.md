# Roadmap v2.5.0 (aberto a mudanças)

Status: **planejado** · milestone `v2.5.0` em [frontend](https://github.com/nunesvictor/ishinydex-frontend/milestone/6) e [backend](https://github.com/nunesvictor/ishinydex-backend/milestone/5).

## Contexto
O app está estável e cada mudança pequena vinha virando deploy próprio (v2.3.0 → v2.4.0 no mesmo dia). A partir de agora as mudanças **acumulam na `main`** e só viram release quando o lote justificar, ou quando houver bug/hotfix. Este plano é a lista viva do próximo lote; itens podem entrar ou sair até fecharmos o roadmap.

## Novo fluxo de deploy
- Feature/bug continua igual até o merge: issue → branch → PR → CI → merge (usuário).
- **Sem bump nem release a cada merge.** Merge na `main` dos submodules não publica nada (o Pages só sai com tag `v*`), então é seguro acumular.
- Cada issue entra numa **milestone da versão** (ex.: `v2.5.0`) nos repositórios envolvidos; a milestone é o roadmap.
- **Release do lote:** quando a milestone fechar (ou o usuário pedir) → um PR de bump dos submodules → `tool/release.py vX.Y.0` → conferir Pages/`sw.js`.
- **Hotfix:** bug que atrapalha o uso sai sozinho como `vX.Y.Z+1`, sem esperar o lote.
- **Catálogo:** só uma release `catalog-*` por lote (a última antes do bump), não uma por PR.
- Atualizar `CLAUDE.md` (seção "Fluxo") e a memória `workflow-issues-prs.md` com essa regra.

### 3. Um detalhe só para slot e espécime (frontend, junto com o 2)
**Por que hoje é diferente:** no dex, cada forma da linha evolutiva tem um **slot naquele dex**; `SpeciesInfo` recebe `dexId` + `onOpenSlot` e, ao tocar, abre esse slot. No inventário não existe dex de contexto: a forma tocada não é um espécime nem um slot, então não havia para onde ir e o `SpecimenDetailView` passa `dexId: null` (só mostra).
- Extrair um corpo comum (ex.: `SpecimenDetailBody` em `personal_dex/presentation/widgets/`) com cabeçalho (sprite, `SpecimenHeadline`, linha da forma) + `FormInfoTabs` + resumo único (hoje `_Summary` do slot e o `summary` do `specimen_detail.dart` duplicam chips/marca/local).
- Diferenças viram parâmetros: linha "caixa · linha/coluna" (slot), chip Depositado/Disponível vs Registrado/Faltante, ações da `DetailActionBar` (cada tela mantém as suas).
- **Decisão:** no inventário, tocar numa forma relacionada abre a **ficha da forma** — bottom sheet só leitura (sprite, `FormInfoTabs` sem espécime), onde dá para continuar navegando pela linha. `SpeciesInfo` ganha um `onOpenForm` usado quando não há `dexId`.
- Testes em `compactSize`/`expandedSize`; 100% de cobertura.
