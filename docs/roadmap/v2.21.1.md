## Contexto
A varredura de 2026-11-02 achou um bug que pode perder dados no sync ([frontend#388](https://github.com/nunesvictor/ishinydex-frontend/issues/388)). O usuário decidiu lançá-lo como patch, sem esperar a [v2.22.0](v2.22.0.md). A release marca a `main` de cada repositório, então o que já estava nela sai junto.

## Itens

### 1. A restauração dos dados à prova de conflito ([frontend#388](https://github.com/nunesvictor/ishinydex-frontend/issues/388))
- **O bug:** um slot cuja box foi apagada (ou um save cujo treinador foi apagado) quebra a restauração com `Null check operator used on a null value`. Acontece quando um aparelho importa com "Substituir" (que marca como apagado o que só existia nele) e outro mexe num desses slots ou saves. Com a falha no meio, ficam os dados pela metade, que a próxima gravação salva e o sync espalha.
- **A correção:**
  - slot sem box e save sem treinador viram órfãos, guardados e devolvidos no próximo arquivo;
  - a restauração monta tudo à parte e só troca se der certo;
  - uma falha ao aplicar o arquivo do sync não grava nem envia nada.
