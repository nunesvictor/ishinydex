# Roadmap v2.13.0 (aberto a mudanças)

Status: **planejado** · milestone `v2.13.0` no [frontend](https://github.com/nunesvictor/ishinydex-frontend/milestone/21).

## Contexto
A versão do **PersonalDex personalizado**. Hoje só dá para criar o dex com o conjunto padrão: a opção "Personalizado" mostra "em breve". O usuário não quer dar mais destaque à criação de dex (como a v2.12.0 faz nas Caçadas) enquanto ela não estiver completa. A versão é dedicada a isso para não atrasar a v2.12.0, que leva as caçadas sem dex.

**Referência:** a planilha "Home Living Dex Organizer", que o usuário usou por muito tempo. Ela organiza os dex com quatro chaves:

| | Regionais | Pré-evoluções | Formas alternativas | Gênero |
| --- | :-: | :-: | :-: | :-: |
| Living Form | ✓ | ✓ | ✓ | ✓ |
| Living Form Lite | ✓ | ✓ | ✓ | |
| Living | ✓ | ✓ | | |
| Final Form Form | ✓ | | ✓ | |
| Final Form | ✓ | | | |

O conjunto padrão de hoje é quase o Living Form Lite.

## Itens do lote

### 1. PersonalDex personalizado ([frontend#34](https://github.com/nunesvictor/ishinydex-frontend/issues/34))
- **Base do dex:**
  - **nacional:** com três chaves (regionais, pré-evoluções e formas alternativas); os nomes da planilha viram atalhos;
  - **por região ou jogo:** a pokédex de um jogo, na ordem regional, com os jogos dos saves primeiro. O catálogo já tem essas pokédex;
  - **vazio:** para montar do zero.
- **Prévia** de formas e boxes, como hoje.
- **Editar formas** num dex existente: busca, filtros e marcar e desmarcar.
- **A decidir no mock:**
  - o que acontece com as boxes ao inserir ou remover uma forma no meio: reorganizar com aviso ou pôr no fim;
  - a forma removida com espécime depositado: ele volta para o inventário, nunca some;
  - a regra do Final Form para evoluções ramificadas, regionais e de forma.
- Mock antes.
- Custo: grande, do tamanho da v2.11.0. Só frontend.
