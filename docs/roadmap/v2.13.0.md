# Roadmap v2.13.0 (aberto a mudanças)

Status: **planejado** · milestone `v2.13.0` no [frontend](https://github.com/nunesvictor/ishinydex-frontend/milestone/21).

## Contexto
A versão dos **PersonalDex pré-moldados**. Hoje só dá para criar o dex com o conjunto padrão: a opção "Personalizado" mostra "em breve". O usuário não quer dar mais destaque à criação de dex (como a v2.12.0 faz nas Caçadas) enquanto ela não estiver completa. A versão é dedicada a isso para não atrasar a v2.12.0, que leva as caçadas sem dex.

**Referência:** a planilha "Austin John's Home Living Dex Organizer", de **Austin John** (canal *Austin John Plays*), [divulgada pela PokeJungle](https://pokejungle.net/2023/03/27/how-to-organize-pokemon-home-for-a-living-dex/). O usuário a usou por muito tempo. Ela organiza os dex com quatro chaves:

| | Regionais | Pré-evoluções | Formas alternativas | Gênero |
| --- | :-: | :-: | :-: | :-: |
| Living Form | ✓ | ✓ | ✓ | ✓ |
| Living Form Lite | ✓ | ✓ | ✓ | |
| Living | ✓ | ✓ | | |
| Final Form Form | ✓ | | ✓ | |
| Final Form | ✓ | | | |

O conjunto padrão de hoje é quase o Living Form Lite.

## Itens do lote

### 1. PersonalDex pré-moldados ([frontend#34](https://github.com/nunesvictor/ishinydex-frontend/issues/34))
- **Nacional, com três chaves:** regionais, pré-evoluções e formas alternativas. Os nomes da planilha viram atalhos.
- **Por região ou jogo:** a pokédex de um jogo, na ordem regional, com os jogos dos saves primeiro. O catálogo já tem essas pokédex.
- **Prévia** de formas e boxes, como hoje. O dex nasce da base e não muda depois de criado, como o padrão de hoje.
- **A decidir no mock:** a regra do Final Form para evoluções ramificadas, regionais e de forma; o lugar da escolha de região ou jogo no fluxo.
- Mock antes.
- Custo: médio. Só frontend.

## Fora do lote
- **Dex 100% personalizado** ([frontend#248](https://github.com/nunesvictor/ishinydex-frontend/issues/248)): editar formas, filtros por categoria e tipo e começar vazio. Serve a dex temáticos (gatos, lendários…). Fica no backlog: é a parte mais cara, por causa das boxes que se deslocam e dos espécimes de formas removidas.
- **Diferenças de gênero** (a quarta chave, o Living Form completo):
  - [backend#120](https://github.com/nunesvictor/ishinydex-backend/issues/120): o catálogo;
  - [frontend#247](https://github.com/nunesvictor/ishinydex-frontend/issues/247): o slot com gênero e um schema novo do arquivo.

  Ficam no backlog.

## Cuidados
- **Créditos a Austin John:** a classificação vem da planilha dele. Usamos a ideia, não os dados. Os créditos aparecem em Sobre o iShinyDex (nos dois idiomas, com o link), na ajuda do Novo PersonalDex e no README.
- **Sem schema novo:** o dex continua sendo formas em slots. Nada muda no arquivo de dados até a etapa de gênero.
- **Dex que já existem** não mudam sozinhos.
- Textos novos nos dois ARBs, com teste em inglês.
